# CoreProse

**AI-powered content platform with verified sources.**

CoreProse generates high-quality, factual content backed by real sources. Every claim is verified, every source is cited.

## Features

- **Zero Hallucinations** — Every statement is grounded in verified sources
- **Source Transparency** — Full citations with links to original sources
- **AI-Powered Writing** — Leverages advanced AI for natural, engaging content
- **Multi-language Support** — Content generation in English and French
- **SEO Optimized** — Built-in optimization for search engines
